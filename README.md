# greedy-bastards-js

Browser port of Greedy Bastards, an arena melee game, in plain JavaScript with
p5.js. Playable: **https://zednaked.github.io/greedy-bastards-js/**

Written in 2022 and not maintained. The art and the fonts in this repo are mine.

The game went on to other shapes: a VR pass
([gbvr](https://github.com/zednaked/gbvr)) and desktop builds
([greedy-bastards-releases](https://github.com/zednaked/greedy-bastards-releases)).

MIT, including the code. The artwork under `Arte/` is not.
